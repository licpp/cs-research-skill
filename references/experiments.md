# 实验判断：证据、归因与投入

## 比较条件定义了结果的含义

一个指标值对应特定输入、可见信息、任务约束、评价器与资源预算。候选范围、处理边界、数据过滤、预处理或后处理变化，都可能改变它测量的能力。

复用公开或历史结果时，核对实际文件、代码入口和关键配置。论文描述、公开默认值与运行文件有差异时，以固定且可追溯的实验版本建立比较。

同一来源的不同长度、规模、稀疏度或负载是实验设置，其证据独立程度由实际来源与构造决定。

冲击 SOTA 时，比较与核心机制最接近的强工作，明确已发表结果和本地运行的来源。任务目标决定采用固定预算下的质量、固定质量下的成本，或完整资源—质量关系。

## 强对照排除了什么解释

对照的价值由它排除的替代解释决定。与新机制最直接竞争的经典或简单方法，往往比增加许多方法名称更有信息量。

额外计算、更多样本、更好预处理、不同输入与新机制都可能带来提升。匹配对照分离这些因素；预算不同的方案同时呈现相应代价。

学习、蒸馏和表示比较的具体对照见 [学习模型专项](learning-models.md)。

## 实验精度由决策代价决定

方向探索关心信号是否值得追踪。代表性输入、有限配置和较小预算能快速排除明显弱方向，留下机制线索。细致验证优先投入有信号的方向。

论文主张关心结论是否经得起比较。目标规模、完整评价条件、关键对照和相关变异来源共同决定证据强度。

粗筛的关键是保留影响机制的输入结构与比较关系。缩小实例数、配置数或预算时，判断它是否改变瓶颈；系统计时需要足够重复来辨别噪声。

单次方向性结果与最终证据各有用途。负结果对应当时的实现、输入和预算，正结果回到目标条件后才确定适用范围。

## 一个实验应减少关键不确定性

每轮比较应能改变关于某个机制、瓶颈或选择的判断。参数继续变化而结论不变，新增运行的价值会下降。

相互作用需要对照支持。基础方案、变化 A、变化 B 与 A+B 的小型比较可以区分独立作用和交互，并决定哪个方向值得扩展。

理想化中间结果、关闭模块或替换策略能估计改进空间。诊断上界与可实际部署的结果分别承担定位和性能论证。

## 平均结果背后的变化决定下一步

平均收益可能掩盖修复和新错误的抵消、成本在环节间转移或仅少部分实例受益。

| 观察 | 有价值的解释入口 |
|---|---|
| 中间指标改善，最终指标不变 | 目标对应关系、下游瓶颈、误差传播 |
| 小改动造成输出突变 | 数值精度、边界条件、离散决策 |
| 复杂方案弱于简单方案 | 信息保留、目标、优化程度与预算 |
| 小规模有效，全量失效 | 输入覆盖、复杂度、内存与通信 |
| 不同实例或负载差异明显 | 输入规模、结构、难度与运行环境 |

某个策略在特定条件下强，可能支持条件选择或分工。判断其实际价值需要该条件在目标分布中的覆盖，以及推断时能否观察到相应特征。

## 增量、互补与复杂性价值各有证据

| 要建立的认识 | 对应比较 |
|---|---|
| 当前方案依赖某组件 | 匹配配置下删除或替换该组件 |
| 两类机制提供互补价值 | 独立组件、简单组合与最终方案 |
| 复杂结构带来额外价值 | 充分优化的轻量替代及效果—成本比较 |
| 某机制在何种条件下有效 | 分组、扰动、规模或覆盖分析 |

直接删除、重优化和独立替代改变的条件不同。删除一个组件连带改变其他组件输入时，固定配置删除与适配后重优化分别解释组件依赖和替代能力。

完整组件和其内部一个小设计的增量分开计算。辅助目标可能改善一类质量而牺牲另一类；主张的尺度应与实际增量和取舍相符。

## 稳定性属于特定变异来源

随机算法种子、学习过程、输入实例、工作负载与运行噪声测量不同变化。确定性算法可通过实例和规模检验稳健性；系统计时关注预热、并发、背景负载及重复测量。

统计检验的单位与结论对应。实例间差异、同一实例重复计时和同一预测上的重采样各有含义。按任务选择配对比较、区间和多重比较处理。

聚合方式也定义指标。先逐实例计算再平均，与先汇总再计算可能不同。均值、分位数、几何平均等摘要按任务选择。

## 成本属于一个明确的执行范围

构建或训练、常驻执行、核心阶段与端到端耗时对应不同范围。缓存、加载、精度、批量/并发、运行环境和测量边界一起决定成本。

资源—质量取舍比一个孤立速度值更能解释方法价值。按核心目标关注正确性、质量、可行性、延迟、吞吐、内存或能耗。

## 结果来源支撑归因与继续研究

采用配置、实例集合、实现、输出与评价器共同确定一个实验结果。候选、已验证与论文采用方案保持可辨识，历史版本用于解释演变。

原始输出和运行记录支持配对分析、重算与恢复；关键工件管理见 [实验运行](execution.md)。论文采用的结果与方法、图表和计时保持同一版本。
