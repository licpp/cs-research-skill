# 科研绘图：SVG 源稿、矢量输出与版面验证

## 按图的用途选择工具

| 图的用途 | 优先方法 | 主要交付 |
|---|---|---|
| 方法框架、流程、概念示例 | SVG 或能稳定输出 SVG 的绘图代码 | SVG 源稿、矢量 PDF、PNG 预览 |
| 实验曲线、柱形、散点和分组图 | Python/Matplotlib、PGFPlots 等数据驱动工具 | 绘图代码、数据、PDF/SVG |
| 需要逐对象编辑的演示图 | 原生 PPT 对象，结合 SVG 公式与图标 | PPTX 与渲染预览 |
| 照片、写实插画与纹理 | 图像工具生成或编辑，按需要嵌入矢量版式 | 位图素材与版式源稿 |

新论文框架图优先采用 SVG。它便于精确控制位置、间距、层级和公式，也方便稳定导出。用户已有满意图时，从其最新版继续，保留布局、图标和风格。

项目已使用稳定的 TikZ、绘图脚本或其他矢量源时，优先沿用可编辑工作流；按目标交付选择格式。

PPT 适合人工逐对象调整。出现自动换行、字体替换、公式变形或导出偏移时，可把出版图迁移到 SVG，并按用户需要继续维护演示稿。

## 先定结构和实际尺寸

先画流程草图，确定输入、核心机制、构建/执行阶段及输出。把基础组件和主要设计分出视觉层级，给核心设计足够空间。

按论文单栏或双栏宽度设计画布。横向流程用较宽布局；图太高时，重排竖向链、压缩辅助区域和图例，保持主要文字大小。

在同一物理单位下，按“源图字号 × 插入宽度/源图宽度”估算最终字号。最终正文标签通常可从约 8–10 pt 的视觉大小起步，再结合模板与内容检查。

完整结构负责让读者辨认信息流，局部坐标、内边距与路由负责精细可读性。已有满意的结构和风格保持稳定，局部问题用局部调整解决。

## 稳定构建 SVG

将画布尺寸、配色、字号、边框、圆角、间距和箭头定义为统一样式。用函数或组件生成重复模块，例如矩阵、节点、队列、记录、处理单元和模块框。

使用原生 SVG 形状、路径、text 和 tspan。显式指定字体、字号、对齐、行间距和换行位置。给标题、公式、图标和正文分别留出稳定边距。

采用清楚的图层次序：背景/模块容器 → 连线 → 内容 → 标签。连线从端口出发，优先短直线和少量直角转折。给箭头尖端、折点、图例和导出边界留出空间。

框中内容发生变化时，重新核对文本包围盒和模块边界。长文本先缩短为标签，细节移到 caption 或正文。

## 字体与公式

常规标签采用环境中实际可用的字体，整图保持统一。SVG 编辑源保留文本；交付 PDF 时检查字体嵌入，必要时另存文字转路径的出版副本。

公式使用 LaTeX、MathJax、KaTeX 或 Matplotlib mathtext 等合适引擎生成矢量形状，核对符号、上下标、粗体和基线。将公式源文本与生成脚本一同保留，后续修改通过源表达式再生成。

复杂公式放在独立区域，围绕其可读尺寸规划版面。方法图只保留识别机制所需的核心式子，推导交给正文。

PPT 中分别检查文本字体与公式渲染。根据交付要求采用原生公式或矢量公式；导出后检查是否发生替换、裁切和基线偏移。

## 把文字转成视觉机制

概览图中的模块用“图形结构＋短标签”表达：

- 数据与结构：矩阵、序列、图、队列和存储布局。
- 计算：变换、搜索、聚合与分支。
- 状态变化：构建、更新、执行与输出的前后对照。
- 交互：数据流、控制流和资源依赖。
- 组件性质：用统一线型、颜色或图例区分基础模块与新增设计。

以机制的完整性决定精简范围。占位段落可以变成图形，重要的输入、交互与输出持续可见。

基础组件可压缩为短流程或图标；主要设计展开到“输入 → 关键交互/运算 → 输出”的内部结构。概览图用清楚的接口连接这些层级，让读者既看到完整方法，也识别贡献所在。

文字过多时，先用状态、向量、结构和操作替代解释句；模块过空时，补出关键计算关系。调整后按论文尺寸重新检查信息密度。

## 用贯穿示例检查技术逻辑

选定一个示例后，全图沿用同一输入、规模和状态。明确输出的范围与含义，让图标、数据形状、中间处理和最终结果一一对应。

分别核对各阶段的处理粒度。例如数据按块处理、状态按对象更新时，使用对应的形状和边界。将输入、控制信息、中间状态与后处理接到实际实现的位置。

概念图保持比较条件一致。展示不同策略时，沿用相同输入和约束，突出策略造成的变化。用边框表达成员关系，用箭头表达实际的数据或控制流。

图中的每条关键箭头都能对应实现中的输入、运算或依赖。涉及学习模型时，训练与推断分别展示实际目标和信息；涉及系统时，区分构建、运行及资源关系。

## 统计图从结果文件生成

图和表读取同一份锁定结果。坐标轴、图例和 caption 说明对象、单位、分组、比较版本及误差条含义。

比例指标的绝对变化按需要用百分点，其他指标保留原始单位；相对变化用比例，并与正文统一。分组分析记录分组规则、阈值及每组实例数。

观察到局部下降或非单调关系时，让图形保留真实形状，并围绕实际支持的发现解释。

## 导出与验收

采用当前环境可用的矢量渲染器，导出 PDF 和 PNG。检查实际导出结果，尤其是字体、公式、箭头、透明度、描边和裁切边界。

把 PDF 插入论文后重新编译，在实际页面检查：图高与正文比例、最终字号、caption、留白及与相邻图表的关系。依次修正源稿、重新导出、重新编译。

常见问题按下面处理：

| 现象 | 处理方法 |
|---|---|
| 图很高，缩小后文字难读 | 横向重排模块，压缩辅助区，保留字号 |
| 箭头头部缺失 | 检查路径长度、marker、图层遮挡与裁切 |
| 文本碰边或换行漂移 | 固定换行，扩大内边距，检查目标字体的包围盒 |
| 公式大小或基线不一致 | 用同一公式引擎和字号规则重新生成 |
| 图标过于抽象 | 复用同风格、易识别的矢量图标，统一尺寸 |
| 局部拥挤 | 缩短标签、调整模块边界和连线，释放该区域空间 |
| PPT 导出与编辑时不同 | 对照导出预览，改用 SVG 出版源或修正字体与文本框 |

需要原生可编辑 PPT 时，保留文本框、形状和连接符，说明矢量公式或图标的实际编辑方式。交付中区分原生对象、嵌入 SVG 和整图预览。

保存 SVG/绘图代码、公式源、PDF 与预览的对应版本。论文实际引用的文件同步更新，方便继续精修。
