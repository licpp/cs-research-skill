# 学习模型专项

涉及训练、蒸馏、表示学习、生成或检索时，读取与当前机制有关的小节。通用实验设计沿用实验指南。

## 训练与评价接口

锁定数据划分、预处理、目标、可见信息和评价器。特征、关系索引及监督视图按划分构建；存在来源样本自重建时，检查是否需要来源排除。

模型产生二级监督时，检查训练记忆对监督质量的影响，必要时使用留出或 OOF 预测。

把验证集用于配置选择，提前保留最终核验数据。接手已有开发历史时，记录数据曾参与哪些决策。

复用 checkpoint 前核对模型结构、训练开关、输入比例、特征、损失权重及输出接口。正式 baseline 以适当收敛和搜索预算建立。

## 分离新机制与额外训练

增强预训练模型时，让新方案与继续训练对照共享初始化、训练步数及任务相关的数据构造。蒸馏实验保留同样训练样本、教师权重为零的对照；表示比较使用匹配的下游训练。

预训练 checkpoint 作为额外参考，匹配对照用于组件归因。根据研究目标，比较固定计算预算或固定质量下的效果与成本。

## 让监督对象匹配目标

多输出预测先明确目标是完整联合对象，还是各输出的边际质量。希望覆盖所有正例时，让每个正例获得相应监督；允许部分命中的指标应在目标设计和验证中体现。

训练和推断对齐输入视图、条件信息及可见范围。小规模试验用固定视图接通；正式训练按任务需要覆盖位置、变换或集合划分。

损失下降而任务指标停滞时，检查概率校准、排序边界、分布差异以及下游决策。先诊断信息与目标，再扩展网络规模。

## 调整信息的使用位置

表征具有局部价值时，比较它作为直接表示、条件信息、预测头输入或训练监督的效果。选择让信息在主要错误发生处发挥作用的接口。

冻结主模型可用于低成本判断新增信息的价值。固定输出的权重融合进入平台后，尝试让可训练的预测头、目标或条件化机制直接学习最终任务，保留匹配的简单头作对照。

新增任务目标出现取舍时，先确定主评价目标和必要约束，再考虑辅助监督。辅助监督可以保持有用结构、邻域、分布或不变性；用相应的主/辅指标检验其实际作用。

代表性设置上的信号决定新接口或目标是否值得扩大训练与验证投入。

## 以有效基线为起点

经典或非参数模型很强时，比较两者读取的信息和实际处理的关系。精确记忆与聚合向量可能保留不同信息；局部关系与整组对象的目标也应分别定义。

需要保持已有行为时，可以采用零初始化残差、可控门控或等价参数化。先确认初始化输出与基线对应，再训练并由验证表现选择配置。

验证选择初始化状态时，将其记为有效回退；训练后增量按实际结果报告。进一步改进可以来自新的监督、信息或决策方式。

## 表示与 checkpoint 的兼容性

更换 tokenizer、词表、离散代码、标签映射或特征维度时，检查旧模型参数的输入含义。根据变化选择重训、映射、适配或重新构建索引。

例如代码数相同但代码含义已变，仍需要验证旧权重的兼容性。比较新表示与旧表示时，保留同预算训练对照，并分别衡量表示的内在性质和下游任务质量。

## 候选、生成与最终选择测量不同能力

候选覆盖决定后续选择的上限，最终排名决定已覆盖目标能否被选出。覆盖改善而命中不变，意味着选择环节仍有损失。

生成结构合法、特征相近与准确恢复目标是不同质量。离散代码的前缀合法性、完整对象命中及映射后的评价，分别说明这些环节的表现。

新方案修复与新增错误的抵消，可能解释很小的平均增量。变化所在的置信度、分数间隔或覆盖条件，有助于判断信息在哪些选择上有效。

后处理或评价映射会改变最终结果的含义。将原始输出与后续变化对应起来，才能确定收益由哪种能力带来。

候选集粗筛保留固定实例 ID，正式方案按目标候选范围验证。依赖真实答案限定的候选或类别，用作诊断上界。

异常提升时，选择适合任务的频率先验、随机选择、固定首样本或简单相似度等对照，定位有效来源。

## 有效覆盖决定样本与计算的价值

按输入规模、难度、类别或数据覆盖分层采样。整体弱、困难子集强的教师，可以探索依据输入难度选择性使用，并回到完整分布验证。

冻结特征与模型时，缓存 logits、特征和逐样本输出，在 CPU 上筛分数融合、门控与排序规则。上下文随决策变化时，重新计算依赖该上下文的部分。

结构、图或记忆模块的有效训练规模取决于它实际作用的样本。总样本数与有效覆盖率共同决定训练规模和模型容量是否匹配。

若昂贵教师整体弱、特定难例上强，可把主模型产生的困难样本用于离线监督。用同样困难样本、相同训练预算且关闭教师信号的对照，判断收益来自教师还是样本选择。

## 随机性与组合收益

分别记录初始化、数据顺序、数据增强与推断采样等随机因素。按所声称的稳定性安排独立运行。

组合模型比较独立分支、固定组合、学习组合及匹配的简化替代。推断删除、重新训练与独立单分支分别标注。

为子机制计算自身增量，例如一个条件输入或辅助损失。按质量、泛化和成本上的实际作用安排它在论文中的位置。
